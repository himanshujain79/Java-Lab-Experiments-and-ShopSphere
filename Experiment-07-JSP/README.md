# Experiment 07: JSP Student Application

## Aim
To develop a student application using JavaServer Pages (JSP) and a Java Servlet.

## Technologies
- Java
- JSP
- Java Servlets
- Maven
- Apache Tomcat

## Project Files
- `pom.xml` - Maven configuration.
- `src/java/com/servlet/HelloServlet.java`
- `src/main/webapp/` - JSP pages.

## How to Run
1. Install the JDK, Maven and a compatible servlet container.
2. Open the project in an IDE.
3. Resolve the Maven dependencies.
4. Build and deploy the application.
5. Open the deployed application in a browser.

## Learning Outcome
Understand JSP pages and servlet-based web applications.
