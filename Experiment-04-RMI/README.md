# Experiment 04: Java RMI

## Aim
To demonstrate Remote Method Invocation (RMI) in Java.

## Technologies
- Java
- Java RMI

## Project Files
- `Calculator.java` - Calculator interface.
- `CalculatorImple.java` - Calculator implementation.
- `Server.java` - Server program.
- `Client.java` - Client program.

## How to Run
1. Install the JDK.
2. Compile all Java source files.
3. Start the RMI server according to the implementation.
4. Run the client and test the remote operations.

## Learning Outcome
Understand communication between Java programs using remote method calls.
