# Experiment 02: Calculator

## Aim
To develop a calculator application using Java.

## Technologies
- Java
- Object-Oriented Programming

## Project Files
- `cMain.java` - Application entry point.
- `cController.java` - Controller logic.
- `cModals.java` - Model-related logic.
- `cViews.java` - View-related logic.

## How to Run
1. Install the Java Development Kit (JDK).
2. Open this folder in your IDE.
3. Compile the Java source files together.
4. Run the `cMain` class.

## Learning Outcome
Understand Java classes and the separation of application logic.
