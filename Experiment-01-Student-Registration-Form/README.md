# Experiment 01: Student Registration Form

## Aim
To demonstrate a student registration form using Java.

## Technologies
- Java

## Project Files
- `studentregistration.java`

## How to Run
1. Install the JDK.
2. Open this folder in your Java IDE.
3. Compile `studentregistration.java`.
4. Run the class containing the `main` method, if present.

## Learning Outcome
Understand the Java concepts demonstrated by the student registration program.
