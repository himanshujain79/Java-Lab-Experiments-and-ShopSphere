# Experiment 06: Java Servlet Application

## Aim
To demonstrate Java Servlet concepts through a web application.

## Technologies
- Java
- Java Servlets
- HTML
- Maven
- Apache Tomcat

## Project Files
- `pom.xml` - Maven configuration.
- `src/main/java/com/servlet/` - Servlet classes.
- `src/main/webapp/` - HTML pages.

## Concepts Covered
The source files include servlet-based pages and examples related to login, cookies, students and application filters/listeners.

## How to Run
1. Install the JDK, Maven and a compatible servlet container.
2. Open the project in an IDE.
3. Build the project using Maven.
4. Deploy the application to the servlet container.
5. Open the deployed application in a browser.

## Learning Outcome
Understand servlet request handling and basic web application components.
