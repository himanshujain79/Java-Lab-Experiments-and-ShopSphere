# Experiment 05: Client-Server Application

## Aim
To demonstrate client-server communication using Java.

## Technologies
- Java
- Socket Programming

## Project Files
- `Server.java`
- `Client.java`

## How to Run
1. Install the JDK.
2. Compile both Java files.
3. Start the server first.
4. Run the client in another terminal.
5. Ensure the host and port settings match in both programs.

## Learning Outcome
Understand the basic working of Java client-server communication.
